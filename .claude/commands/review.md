description: 現在の変更をレビューし、重大な問題から順に報告する
---

`git diff`（未コミットの変更）と、必要なら直近のコミットを読んで、コードレビューをしてください。

確認する観点（上ほど優先）:

1. セキュリティ: 秘密情報の混入、認証・認可の漏れ、入力チェック、XSS、SQL インジェクション
2. 正しさ: 業務ルール（習熟度 0〜3、「できる人」は習熟度2以上かつ在籍中、新人は入店3か月以内）とのずれ、境界値、エラー処理
3. 2つのバックエンドの一致: Java と `frontend/lib/server/data.js` で、ルート・レスポンス形式・検証・日本語メッセージが揃っているか
4. 保守性: 命名、重複、1つの関数に役割を詰め込みすぎていないか

指摘には重大度（高・中・低）を付け、重大なものから並べてください。各指摘には、該当ファイルと行、問題が起きる具体的な場面、修正案を書いてください。問題がなければ、そう書いてください。
