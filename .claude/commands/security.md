---
description: 公開リポジトリ向けのセキュリティ点検をする
---

このリポジトリは公開されています。コミットした内容はすべて公開情報として扱い、次の点を点検してください。

1. 秘密情報: パスワード、API キー、JWT の署名鍵、DB の接続情報がコードや設定ファイルに書かれていないか。`.env*` の値は読まず、出力もしない
2. 認証: ログインが必要な API がすべて保護されているか（Java は `SecurityConfig`、JS は `requireUser`）
3. 認可: ログインできる人の範囲（`AllowedUsers`、`isAllowedEmail`、`OPEN_SIGNUP`）が意図どおりか
4. 入力チェック: 新しい入力項目が、サーバー側で検証されているか
5. 環境変数: 本番やデモで必要な値が、未設定のときに安全側（起動しない・503 を返す）に倒れるか
6. 依存関係: `npm audit` の結果に新しい高リスクの指摘がないか

見つけた問題は重大度（高・中・低）を付けて報告し、修正方法を提案してください。修正は、確認を取ってから行ってください。
